# Original 16 archetypes

Archetypes are **descriptive product constructs** mapped from four Big Five domain means: Openness, Conscientiousness, Extraversion, Agreeableness.

- High ≥ 3.25, Low ≤ 2.75, otherwise mixed / leaning.
- Pattern string `OCEA` with H/L, see `ARCHETYPE_GRID` in `app/scoring/archetypes.py`.
- Primary = exact grid cell; secondary = nearest Hamming neighbor.
- Emotional stability flavors interpretation but does not change the 16-cell grid.
- Not Myers-Briggs types. Not independently validated categories.
