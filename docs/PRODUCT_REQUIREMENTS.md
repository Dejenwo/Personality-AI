# Product requirements (implemented subset)

Full Option C scope lives in MASTER_PROMPT.md. This file tracks what the current codebase actually satisfies.

## In scope and implemented

- Adult 18+ educational personality platform
- Free Quick Discovery + Big Five
- Premium-gated original inventories (entitlement enforced)
- Deterministic scoring and original archetypes
- Dashboard, coach, growth, journal, habits, goals
- Career / leadership / relationship modules with ethical constraints
- Reports (interactive + PDF)
- Admin and enterprise portals (MVP)
- Privacy export/delete/consent

## Explicit non-requirements for launch until reviewed

- Scientific marketing claims of independent validity for original inventories
- Clinical use
- Employment decisions
- Under-18 products
