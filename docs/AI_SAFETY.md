# AI safety

- Coach is educational, not a licensed professional.
- Scores are read-only context from stored results.
- Crisis phrases trigger a fixed response (988 / IASP / emergency services).
- Injection phrases stay in-role.
- Daily message caps: 8 free / 80 premium (config).
- Provider failures fall back to the educational engine.
- No training on private user data in this codebase.
