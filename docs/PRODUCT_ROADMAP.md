# Product roadmap

Phases 1–8 of the master prompt have working code in this repository. Phases 9–20 have functional MVP surfaces. Phases 21–25 remain incomplete (hardening, load tests, beta, launch).

4. Wire OpenAI/Anthropic keys behind the existing provider interface
5. Stripe test-mode when a key is provided
6. Native Expo assessment flow sharing the API client
