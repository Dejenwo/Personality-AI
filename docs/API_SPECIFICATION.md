# API specification

OpenAPI is generated live at `GET /api/v1/openapi.json` and Swagger UI at `/api/docs`.

Prefix: `/api/v1`.

Major groups: `/auth`, `/users/me`, `/assessments`, `/sessions`, `/results`, `/personality`, `/coach`, `/growth`, `/journals`, `/goals`, `/habits`, `/careers`, `/leadership`, `/emotions`, `/relationships`, `/reports`, `/subscriptions`, `/referrals`, `/notifications`, `/privacy`, `/organizations`, `/admin`.
